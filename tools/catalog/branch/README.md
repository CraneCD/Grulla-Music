# Grulla Music score catalogue

This branch is the online score catalogue that the Grulla Music app searches in
"Find scores". It holds data only, no code: the app's code is on the main branches.

- `catalog.json.gz`: the index (title, composer, instruments, bars, source, licence, file).
- `scores/<source>/<shard>/<id>.mxl`: the scores, compressed MusicXML.

It is generated by `tools/catalog/build_catalog.py` on the app's main branch, and replaced
as a whole (one commit) whenever it is rebuilt. To clone the app without it:
`git clone --single-branch --branch main ...`.

See `LICENSE-NOTES.md` for where the scores come from and their licences.
